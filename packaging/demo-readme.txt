SoundCraft AAF Preview — demostración original (MIT)

1. Copia la app a una carpeta local y ábrela.
2. File > Import > Session Data... > Browse: elige Montaje sintético.aaf.
3. Carpeta de medios: esta misma carpeta Demo AAF. Analyze AAF.
4. Revisa 2 pistas (mono/estéreo), 3 cortes, 48 kHz, 25 fps, inicio 01:00:00:00.
5. Import. Reproduce desde el comienzo: tonos suaves e impulsos de referencia.
6. Extiende un borde del primer clip mono y deshaz; las fuentes contienen 8 segundos completos.
7. Guarda la sesión en una carpeta nueva antes de expulsar el DMG.

Esta demo no contiene material de Pro Tools ni audio del proyecto Pinguino.
Distribución de desarrollo no oficial. No hay equivalencia de plugins, automatización ni ruteos.
