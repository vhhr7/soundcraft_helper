# Demostración gráfica de cinco minutos

Preparación: abrir **SoundCraft AAF Preview**, comprobar salida de audio activa y tener una sesión vacía; usar `demo/AAF con espacios ñ/Montaje sintético.aaf` o Pinguino local con sus WAV. Ensayar antes de clase y conservar copia del material.

| Tiempo | Acción y explicación |
|---|---|
| 0:00–1:00 | File → Import → Session Data; Browse, carpeta WAV y Analyze AAF. Leer propiedades y avisos. |
| 1:00–2:00 | Seleccionar pistas, mantener timecode absoluto y offset 0; explicar que cada pista se añade como nueva. Importar. |
| 2:00–3:00 | Go to first imported clip, cerrar el reporte y reproducir un fragmento. Enseñar cortes y silencios independientes. |
| 3:00–4:00 | Extender un borde sin superar el audio disponible, mostrar handles y deshacer. Guardar en carpeta nueva: fuentes completas, no consolidación por pista. |
| 4:00–5:00 | Explicar límites: AAF externo, sin OMF, plugins, automatización ni fundidos paramétricos. Comparar un corte con Pro Tools y mostrar el reporte. |

Las pruebas automáticas validan tiempos y ventanas de fuente; una clase requiere además un ensayo de reproducción, guardado y reapertura con el hardware del aula. Si se mueve el cursor al principio de la sesión puede haber silencio antes del primer corte; usar Go to first imported clip. Revisar que el motor de audio y la salida estén activos.
